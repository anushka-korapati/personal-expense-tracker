# Personal Expense Tracker

A Python-based Personal Expense Tracker for managing income and expenses using SQLite.

## Features

- Add income and expenses
- Edit transactions
- Delete transactions
- Search transactions
- Calculate total income and expenses
- Calculate current balance
- Export transaction data to CSV
- SQLite database management

## Technologies Used

- Python
- SQLite
- CSV

## Project Overview

This project is designed to help users manage personal financial transactions in a simple and organized way. It uses Python for application development and SQLite for storing transaction data.
